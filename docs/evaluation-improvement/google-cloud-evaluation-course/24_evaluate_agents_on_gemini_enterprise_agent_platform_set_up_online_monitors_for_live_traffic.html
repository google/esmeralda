An online monitor runs a scheduled loop. It queries a sample of traces from Cloud Trace and Cloud Logging, evaluates them with your configured metrics, and reports the scores. So you catch quality drift as a falling score before it becomes a support escalation. You build one with the New monitor form on the Online monitors tab.

Warning:

A monitor runs as an OnlineEvaluator resource under the project service account, and anyone who can create one can attach it to any agent in the project. Restrict monitor creation to authorized admins.

Tip: Sampling percentage is your primary cost control. Scoring every trace is expensive, so score a fraction and cap it with Max samples per run.
