A running monitor writes scores, but scores only help once you can see the trend and drop into the conversation behind a dip. This lesson shows how to read aggregate quality over time across your monitors, then open a single trace to read its score and the judge's rationale.

The centralized gateway architecture

The evaluation dashboard plots quality as a time series, so you spot a slow decline before users complain. You find it under a deployed agent's Dashboard tab, in the Evaluation subsection. It charts each configured metric across your monitors over the timeframe you pick, such as response quality, safety, hallucination, and tool use quality.

The signal to read is a dip in a metric line: it points you at the change or the period that introduced the drop.
