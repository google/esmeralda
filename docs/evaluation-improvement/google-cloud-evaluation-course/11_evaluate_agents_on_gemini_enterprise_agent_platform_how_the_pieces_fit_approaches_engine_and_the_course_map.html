The centralized gateway architecture

Gemini Enterprise gives you two ways to evaluate the agent.

Offline evaluation scores data you already have, such as captured traces, sessions, or simulated sessions. You run it from the New experiment wizard on the Evaluation page.

Online monitoring scores a sample of live production traffic on a recurring schedule. You run it from the Online monitors tab. Offline evaluation is the focus of Module 5. Online monitoring is Module 6.

Within offline evaluation, the cadence shifts with the lifecycle stage. You run ad-hoc checks while developing new agent logic. Then you schedule the same evaluation in a continuous integration and delivery (CI/CD) pipeline for regression testing. Both cadences go through the one New experiment wizard.

Use offline while you build and test, and online once the agent serves real users.

The centralized gateway architecture

Agent evaluation has two entry points to the same underlying eval engine. One is the Google Cloud console wizard, a guided flow with prompts and built-in dashboards. The other is the Agent Platform SDK client, the scriptable path for repeatable runs in a CI/CD pipeline.

This course works in the console, so that is what the lessons show, and the SDK runs the same evaluations through code. Because both reach the same engine, what gets measured does not change between them.

The centralized gateway architecture

Every module from here is one stage of the Quality Flywheel, run in one of the console areas you just toured.

  • Module 2 instruments the agent so the evaluator can read its traces.

  • Module 3 generates eval cases with scenario generation and the User Simulator.

  • Module 4 defines the metrics that grade them.

  • Module 5 runs offline evaluations on the Experiments tab and reads the results.

  • Module 6 monitors live traffic and alerts on drift.

  • Module 7 clusters failures with Automatic Loss Analysis, runs optimization, and re-runs the evaluation to verify the fix, closing the loop.

  • Module 8 is the build-time lane. You evaluate the agent locally with the Agent Development Kit (ADK), Google’s open-source framework for building agents, before it ever deploys. Then you graduate it to the same managed evaluation once it runs on the platform.

Keep this map in mind as you go. Each module then tells you which stage you’re in and which part of the console delivers it.
