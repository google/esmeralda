In this lesson, you'll learn how to execute a model upgrade step-by-step using a structured migration framework.

Upgrading a production model requires addressing both deterministic software challenges and output quality evaluations in parallel. To learn how to meet this challenge, you'll explore a five-phase framework spanning scoping, baselining, optimization, online testing, and production rollout to transform high-risk upgrades into a repeatable, automated operation.

By the end of this lesson, you'll be able to:

  1. 1.

    Explain the different types of evaluation tasks to be tackled during the model upgrade process.

  2. 2.

    Apply a five-phase execution process to upgrade an application or agent to a new model.

The centralized gateway architecture

To execute a model upgrade successfully, split your challenges into two categories and address them in parallel:

Deterministic SDLC type tasks:

Code and infrastructure changes—such as managing adjustment in thinking level parameters, different API response forms, or passing thought tokens between model calls. You test for and resolve these using standard software regression pipelines.

Output quality—ML / stats type tasks:

Changes in model behavior, response quality, length, or style. These require robust, data-driven evaluations.
