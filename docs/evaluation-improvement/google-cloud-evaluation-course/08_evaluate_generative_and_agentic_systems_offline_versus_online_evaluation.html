In this lesson, you'll learn about online evaluation and how to establish a production feedback loop.

Evaluating generative and agentic systems offline in isolated development environments is safe and allows for rapid iteration.

However, offline evaluation cannot predict live user behaviors or catch emergent issues.

To build a reliable system, you must also perform online evaluation and feed the online evaluation data back into offline evaluation as part of the quality flywheel.

By the end of this lesson, you'll be able to:

  1. Differentiate between offline and online evaluation.

  2. Analyze the pros and cons of offline and online evaluation.

  3. Explain the quality flywheel.

  4. Design a feedback loop that captures online interaction logs to continuously update offline evaluation datasets and improve the deployed system.

While offline evaluation is where you perform hill climbing, online evaluation is where you discover what needs to be improved. A high-performing system connects these two environments using a feedback flywheel.

To run the quality flywheel, you follow these steps:

Click the marker numbers in the diagram to learn more.

Capture new online failures
Extract evaluation data
Add to offline evaluation dataset
Hill climb to fix new failures
Deploy fix and monitor online

Running this loop ensures your offline evaluation evolves alongside real customer interactions.
