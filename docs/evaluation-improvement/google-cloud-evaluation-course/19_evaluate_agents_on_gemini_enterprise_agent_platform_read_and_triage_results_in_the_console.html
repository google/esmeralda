The centralized gateway architecture

The evaluation report for a completed run opens with summary metrics, the aggregate scores across all eval cases, so the agent's weakest dimensions stand out before you read a single case.

From the summary you drill into the per-case results, the individual conversations behind the run-wide scores. This takes you from one number to the specific cases worth opening, so a large run stays manageable.

The centralized gateway architecture

The trace holds the detailed record. You follow a failing score from the report into the trace, then backtrack the conversation to the root turn where the agent went wrong. This is the deepest level of triage: the report flags the case, the per-case results name the rubric, and the trace shows the turn.

When a run returns no scores at all, the common cause is missing telemetry, not the engine. Check whether the agent span carries its required attributes, such as gen_ai.agent.name and gen_ai.conversation.id, by opening the same trace in Cloud Trace.

Before you re-run an evaluation that returned nothing, confirm the Cloud Storage output path is set and your environment is authenticated.
