The centralized gateway architecture

The reference architecture chains every feature from this course into one closed loop. You instrument the agent and capture telemetry, generate cases with scenario generation and the User Simulator, define metrics in the Metric Registry, and run offline evaluations. You then monitor live traffic and alert on drift, cluster failures with Automatic Loss Analysis, and optimize.

What makes this a flywheel rather than a one-way pipeline is the feedback loop: the optimized agent version is added to the Agent Registry and submitted to the next evaluation. Build-time ADK evaluation sits alongside this managed loop: it runs on your machine before deployment, then deploys an agent into this architecture.
